# Vue File Generation Rule

When creating a new Vue (.vue) file, always use the following SFC (Single File Component) base structure:

```vue
<template>
  <div class="">
    
  </div>
</template>

<script setup lang="ts">

</script>

<style scoped>

</style>
```
