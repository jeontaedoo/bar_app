# 변경 검증

## 공통 순서

1. `git diff --check`로 공백 오류를 확인한다.
2. 변경 파일의 import, route 경로, 타입과 template 참조가 서로 맞는지 검토한다.
3. TypeScript, Vue 또는 서버 코드가 바뀌면 `npm run build`를 실행한다.
4. 가능하면 변경한 내부 API 또는 페이지를 실제로 호출하거나 브라우저에서 확인한다.

## 변경별 추가 확인

- 화면: loading/error/empty, 키보드 조작, 반응형 레이아웃, 잘못된 route param
- 내부 API: 정상 응답, 입력 오류, 제공자 실패, 비밀값 비노출

## 보고 원칙

- 실행한 명령과 결과만 적는다.
- 현재 존재하지 않는 lint/test 스크립트를 통과했다고 말하지 않는다.
- 외부 API 키, 네트워크 또는 인증이 없어 검증하지 못한 항목은 미실행 사유와 함께 분리해 적는다.
